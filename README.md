# 🚀 ¡Hola! Bienvenidos al repositorio oficial de Prompt & Play 🤖🎮

¡Bienvenido a la biblioteca de código de **Prompt & Play**! Aquí encontrarás todo el código fuente, archivos de configuración, *prompts* y ejecutables que mostramos en nuestro canal de YouTube.

---

### 🕹️ ¿Qué encontrarás en estos repositorios?

- 📱 **3DS Homebrew:** Juegos y pruebas desarrollados con IA para Nintendo 3DS (`.cia` / `.3dsx`).
- 🧱 **Roblox Studio (Luau):** Scripts, sistemas de física, minijuegos y mecánicas generadas por IA.
- 👾 **Desarrollo Retro / SNES:** Audio, gráficos y experimentos en C / PVSnesLib para la Super Nintendo.
- 🤖 **Prompt Engineering:** Los *prompts* exactos usados con Claude AI, ChatGPT y otros modelos.
